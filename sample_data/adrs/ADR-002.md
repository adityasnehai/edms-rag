# ADR-002: Standardize EDMS Retrieval Flow

Status: Accepted
Owner: Platform Team
Last Updated: 2026-05-02 10:00 UTC

## Context
Teams need consistent answers from ADRs, RFCs, meeting notes, postmortems, tickets, and diagrams without leaking data across organizations.

## Decision
EDMS will index this record inside the organization workspace and use hybrid retrieval with linked evidence.

## Consequences
Admins must upload records into the correct data type folder. Search results become easier to trace back to the original decision.

## Considered Options
- Store all documents in one folder.
- Keep typed folders and preserve source metadata.
