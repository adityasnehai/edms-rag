# RFC-002: Improve Knowledge Indexing

Status: Draft
Owner: Search Platform
Last Updated: 2026-05-02 11:00 UTC

## Problem Statement
Search quality drops when uploads are not structured and evidence cannot be mapped to the correct source.

## Proposed Solution
Require clear markdown sections, preserve data type metadata, and rebuild the org-scoped index after upload.

## Alternatives Considered
- Use keyword-only search.
- Use vector-only search.
- Use hybrid search with reranking.

## Trade Offs
Hybrid search adds indexing complexity but improves recall and grounded answers.
